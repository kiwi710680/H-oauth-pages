隱私權政策

應用程式：Kiwi Research Assistant
最後更新：2026 年 10 月 5 日

本政策說明由 Kiwi 維護的 Kiwi Research Assistant（以下稱「本工具」）如何存取、使用、儲存及傳送資料。本工具是以 Hermes Agent 執行的個人研究與工作流程設定；本網站是提供介紹及政策資訊的靜態網站。

1. Google 資料的存取

本工具使用 Google OAuth，依你授予的權限與提出的任務存取 Google Drive 和 Google Sheets。你不需要向本工具提供 Google 帳戶密碼。

  • Google Drive：可能存取檔案名稱、識別碼、類型、資料夾結構與其他中繼資料，以及任務所需的檔案內容；並可依任務需要上傳、整理、更新或刪除檔案。目前的權限範圍為 https://www.googleapis.com/auth/drive，可涵蓋你帳號內的 Drive 檔案，不限於本工具建立的檔案。
  • Google Sheets：可能存取試算表名稱、結構與儲存格內容，並依任務需要建立或更新試算表。目前的權限範圍為 https://www.googleapis.com/auth/spreadsheets。

目前不要求 Gmail、Calendar、Contacts 或 Google Docs API 的專用 OAuth 權限。若未來用途需要改變存取範圍，應先更新政策並重新取得必要授權。

2. 資料的用途

Google 資料用於提供你要求的研究與工作功能，包括搜尋文件、摘要或整理內容、管理檔案，以及讀取和更新試算表。必要的對話與執行紀錄也可能用於維持任務脈絡及排除錯誤。

本工具不將取得的 Google 資料出售、用於廣告投放，或提供給資料經紀商；也不以 Google 資料建立與使用者要求無關的個人剖析資料。

3. 外部 AI 與第三方服務

資料不一定只在你的電腦上處理。Hermes 使用外部模型執行任務時，相關指令、對話、檔案片段、試算表內容或工具回傳結果，可能送至當時設定的模型供應商，例如 OpenAI。

僅應傳送完成你要求之功能所需的資料。不同模型供應商及帳戶方案的保存、日誌和資料使用條款可能不同；本政策不保證所有第三方服務均零保存。在傳送 Google 資料前，應確認所選服務與帳戶設定不會將該資料用於通用 AI／機器學習模型訓練，且適合資料的敏感程度；未確認或不符合時，不應傳送。

若任務需要其他外部服務，應在傳送資料前確認其必要性及授權範圍。請勿輸入未經授權揭露的個人、病人、機密或研究資料。

Google API 服務本身依 Google 的相關條款與政策運作；外部模型服務收到的資料另受該供應商條款與政策規範。

4. 儲存與安全

原始 Drive 檔案與 Sheets 試算表由 Google 服務保存。Hermes 執行任務時，可能在其執行環境中保存下載檔案、輸出檔案、對話、任務紀錄、日誌及備份；若使用外部模型，該服務也可能依其條款保存收到的內容。

Google OAuth access token 與 refresh token 保存在 Hermes 執行環境中的憑證檔案，不應置於公開網站或公開 repository。維護者應限制憑證及資料的檔案存取權限，保護執行環境，並只保留完成工作所需的資料。

本工具不承諾所有本機檔案均以加密方式儲存，也不承諾系統可完全避免安全事件。

5. 保留與刪除

本工具未設定涵蓋所有檔案、對話、日誌及備份的統一自動刪除期限。實際保留時間取決於各項資料所在服務、Hermes 設定及使用者的保存需求。使用者與維護者應定期清理不再需要的資料；第三方服務的保留與刪除則依其條款及可用控制項處理。

  • Google Drive／Sheets 中的資料，可透過 Google 服務的功能管理及刪除。
  • Hermes 的本機檔案、對話及紀錄，需要另行清理；備份中的副本也需要另外處理。
  • 撤銷 OAuth 授權不會自動刪除先前保存或已送至第三方的資料。

如需協助釐清保存位置或刪除方式，可聯絡維護者。

6. 你的選擇與授權撤銷

你可拒絕授權、停止使用本工具，或前往Google 帳戶的第三方連線管理頁面移除本工具的存取權。授權移除後，原有授權將無法繼續用於存取 Google API；再次使用需要重新授權。

你也可透過下方聯絡方式詢問 Google 資料的使用方式。請不要在聯絡郵件中附上 token、密碼或敏感資料。

7. 本網站與 GitHub Pages

本網站不提供登入或資料上傳表單，未嵌入廣告、分析追蹤程式或第三方字型，也未由頁面程式設定 cookie。但 GitHub Pages 作為託管服務，可能為安全目的記錄訪客 IP 等技術資訊，依GitHub 隱私權聲明處理。

8. Google API 資料使用政策

本工具對從 Google API 取得之資訊的使用，以及將該資訊傳送至其他應用程式的做法，將遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。Google 資料僅應用於提供使用者要求的功能，不得用於開發、改善或訓練通用 AI／機器學習模型。

9. 政策更新與聯絡

若資料用途、存取範圍、使用服務或保存方式改變，維護者應同步更新本政策及頁首日期；必要時應在新用途開始前通知使用者並取得新的授權。
